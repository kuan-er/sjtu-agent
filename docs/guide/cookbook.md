# 日常话术库

照抄就能用的问法大全，按场景分类。三种用法等价：直接说自然语言、输入 `/` 斜杠命令、或在 Web GUI 点输入框上方的快捷按钮。

## 三条心法

1. **说人话就行**——它听得懂口语和缩写，「有啥要交的」和「列出本周截止的作业」效果一样；
2. **给足定位信息**——课程名、日期、第几题，信息越全回答越准；
3. **不满意就追问**——「展开讲讲」「换个思路」「只要前三条」，对话就是工作方式。

## 📅 DDL 与作业

```text
这周有什么作业要交？
今天有什么马上到期的东西吗？
把我的 DDL 按紧急程度排个序
 phycai 和 Canvas 的实验报告分别在什么时候截止？
```

背后是一次拉取 Canvas / AI 好课 / 中国大学 MOOC / phycai 的真实数据并分类汇总——这是查出来的，不是编的。等价的快捷命令是 `/ddl`。

## 🗓 课表与成绩

```text
明天上午有课吗？
下周我的课表怎么样？
这学期我加权绩点多少？
数据库这门课我现在多少分？
```

课表自动适配校历调休（开学第一周、节假日挪课都会算）；成绩直连教学信息服务网查询。

## ⏰ 提醒与备忘

```text
帮我记一下明天 14:00 交实验报告
下周一早上提醒我去找导师签字
周五之前提醒我把项目报告发给队友看看
```

提醒默认存本地；想让它在到点时**主动推送**，需要装后台服务：

```bash
sjtu-agent install-daemons   # 一次性配置定时任务
```

## 🍜 吃饭

```text
/eat              # 默认闵行
/eat 徐汇          # 换校区
我现在在东区，想吃点快的不用排队的
我今天在中餐份饭食堂吃了,还挺好吃的
```

推荐结合实时拥挤度 + 你的历史口味；吃完随口告诉它一句，它就把这家记进你的偏好了。

## 🏫 校园事务

```text
帮我预约明天上午去徐汇的校车
宿舍空调坏了，教我在交大办上报修
我的校园卡余额怎么查？
```

这类需求走门户事务工具：它会登录交我办对应的业务页面帮你操作或指引步骤。

## 📰 新闻与资讯

```text
/news                      # 今天有什么校园新闻
/news_block 教务处          # 不想看某类新闻
帮我看下最近水源上关于选课的热帖
web_search 一下 CS61A 是什么课
GitHub 上有没有好用的 LaTeX resume 模板仓库？
```

校园新闻聚合教务处 / 水源 / 交大新闻网 / Canvas，会按你的阅读偏好逐渐个性化；开放性概念问题它会主动联网搜索。

## 📝 作业深度辅导

```text
/hw                # 列出所有作业
/hw do 3           # 第 3 个作业：下载 → 分析 → 生成完整解答
/hw brief 3        # 只出思路摘要
/hw due 7          # 一周内要截止的
```

「do」的完整解答生成依赖本机安装 Claude Code（配置见 README 作业助手章节），只想看思路用 `brief` 就行。**生成的内容务必自己过一遍再提交**——理解了才是你的分。

## 📚 论文与排版

```text
/template                          # 列出内置模板
/template bachelor-thesis           # 套用 SJTU 本科毕业论文模板
/template compile                   # 编译出 PDF
```

也可以直接描述需求：「我要开始写毕业论文了，帮我搭好 LaTeX 工程」。Overleaf 项目还能 `/template clone <id>` 克隆本地改。

## 🖼 发图片 / PDF 给它看

- **Web GUI**：点输入框旁的上传按钮，或直接拖进去；
- **TUI / 终端**：`/attach C:\Users\me\Desktop\题目.pdf`；
- **飞书等 Bot**：直接把文件发进聊天。

然后正常提问就行：

```text
（上传题目截图后）第二题怎么做？给我一个提示就行，别直接报答案
（上传课件 PDF 后）帮我把这份课件划一下考试重点
```

支持图片（配视觉模型）、OCR、PDF 解析；部分解析后端需按提示一键安装（`sjtu-agent install-parse-backends`）。

## 🧠 让它越来越懂你

它的画像来自你的日常对话，不用刻意设置：

- 说「**我去 XX 吃了**」积累食堂口味 → 下次推荐更准;
- 多聊你关心的方向 → `/news` 排序自动偏向它们，不感兴趣随时 `/news_reset` 重来；
- 直接交代长期背景也有效：「我是闵行的大一新生，主修计算机，周末想学日语」。

## ⌨️ 斜杠命令速查

| 命令 | 作用 |
| --- | --- |
| `/ddl` | 查看 DDL 聚合 |
| `/hw` · `/hw do N` · `/hw brief N` · `/hw due N` | 作业列表 / 解答 / 摘要 / N 天内截止 |
| `/eat [闵行\|徐汇\|张江]` | 食堂推荐 |
| `/news` · `/news_block 分类` · `/news_reset` | 校园新闻 / 屏蔽 / 重置偏好 |
| `/template bachelor-thesis` 等 | LaTeX 模板套用 |
| `/attach <路径>` | （TUI）上传附件 |
| `/help` | 看它能做什么 |

记不住也没关系：在输入框敲一个 `/`，Web GUI 和 TUI 都会弹出补全面板。
