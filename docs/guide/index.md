# 新手指南：先看这里

这份指南写给**第一次接触 AI 工具的同学**——不需要任何编程或 AI 背景，只要会开关电脑、能登录 jAccount，就能把 SJTU Agent 用起来。

::: tip 新生的最佳配置时间窗 🎖️
军训期间课程压力小，晚上有整块空闲。趁这段时间把它配好（约 20–30 分钟），9 月 14 日第一周正式上课后，DDL、课表、作业推送就是即开即用的状态——等到第三四周实验报告堆起来再折腾环境，就手忙脚乱了。
:::

## SJTU Agent 是什么

一句话：**一个装在你自己电脑上的校园生活助理**。

它背后连着一个大语言模型（可以理解成一位读过海量资料、什么话题都能聊的学长学姐），同时接上了交大的各种系统：Canvas、教学信息服务网、教务处、水源、交我办……所以它不只是"聊天机器人"，而是**能真的替你去查数据、干事情的助手**：

| 你说 | 它做 |
| --- | --- |
| 「这周有什么要交的？」 | 聚合 Canvas / AI 好课 / MOOC / phycai 的真实 DDL |
| 「明天上午有课吗」 | 查你的真实课表（含调休适配） |
| 「我绩点多少了」 | 直连教学信息服务网查成绩和加权 GPA |
| 「明天 14:00 提醒我交实验报告」 | 注册本地提醒，到点推送给你 |
| 「现在去哪吃」 | 结合实时拥挤度和你的口味推荐食堂 |
| 「帮我看看这道题」 | 读取你上传的图片/PDF，讲解并给思路 |

所有凭据、聊天记录都**只保存在你自己的电脑上**，不上传任何服务器（详见 README 的[安全说明](https://github.com/kuan-er/sjtu-agent#安全说明)）。

## 它不能做什么（诚实版）

- **它不是官方系统**。DDL、成绩、缴费这类重要信息，最终以教务系统/任课老师通知为准；它帮你省的是「开四五个网站挨个查」的时间，不是让你免核对。
- **它可能会出错**。大模型有时会一本正经地说错话（行话叫"幻觉"），尤其是不牵涉工具查询的开放问题。[AI 使用基础](./ai-basics.md)里教你怎么识别和应对。
- **它需要你自己动手装一次**。安装脚本能自动化绝大部分步骤，但下载依赖、填 API Key 这些只能本机完成。
- 部分深度功能（如生成完整作业解答 PDF）还有额外依赖，遇到时它通常会自己提示你缺什么。

## 四种用法，从哪个开始？

四种界面共用同一套大脑和数据，随时切换：

| 界面 | 启动方式 | 适合谁 |
| --- | --- | --- |
| **Web GUI** ✅ 推荐起步 | `sjtu-agent web` → 浏览器打开 | 喜欢网页聊天框、点按钮传附件的新生 |
| 终端对话 | `sjtu-agent` | 开着终端干活的人 |
| Textual TUI | `pip install -e ".[tui]"` 后 `sjtu-agent tui` | 全屏终端党 |
| 飞书 / Telegram / 微信 / QQ Bot | 各自绑定后常驻后台 | 想"在聊天软件里随口问一句"的人 |

Bot 绑定步骤多一些（要去平台申请应用），建议先用 Web GUI 玩熟，回头再看 README 的[多平台 Bot](https://github.com/kuan-er/sjtu-agent#多平台-bot)章节。

## 上手三步走

1. **拿一把钥匙** —— 注册致远一号（交大官方免费 AI 平台），创建你的 API Key：见[从零安装 · 第一步](./install.md#第一步-拿到致远一号-api-key)
2. **装好软件** —— 一条命令克隆 + 安装 + 配置向导：见[从零安装](./install.md)
3. **开始使唤它** —— 从「这周有什么作业」问到「食堂吃什么」，照抄就行：见[日常话术库](./cookbook.md)

中途有任何概念看不懂（API Key？Token？幻觉？），翻一下 [AI 使用基础](./ai-basics.md)那页的小词典；出问题先跑 `sjtu-agent doctor`，再查[排错手册](../TROUBLESHOOTING.md)。
